# importABCatlas 0.2.0.9007 quick start

## Install from the source folder

```r
install.packages("remotes")
remotes::install_local(
  "/path/to/importABCatlas-0.2.0.9007",
  dependencies = NA,
  upgrade = "never",
  force = TRUE
)
```

Restart R or RStudio.

## One-time automatic setup

```r
library(importABCatlas)
setup_importABCatlas()
diagnose()
```

No Python path is required. The package downloads a private Python 3.11 runtime
and its dependencies into the user's cache. The first atlas operation performs
the same setup automatically if this command is skipped.

## Live plan without an expression download

  "Zhuang4",
  download_base = "~/abc_atlas_cache",

  preview_n = 100L

plan_fetch(d, cell_ids = cells, genes = NULL, data_type = "raw")
